## 17. Advanced Top Senior Questions
1. **How do you handle a production memory leak in Python?**
   - Answer: Look at `tracemalloc`, check for circular references that the GC can't clear, and review C-extensions that might not be releasing memory back to the OS.
2. **When would you NOT use FastAPI/Asyncio?**
   - Answer: If the application is CPU-bound (e.g. image processing, heavy math), Asyncio provides zero benefit and actually adds overhead. Use `multiprocessing` or C-extensions instead.
3. **How do you safely deploy a breaking database schema change?**
   - Answer: Never in one PR. Use the Expand-Contract pattern. PR 1: Add new column. PR 2: Write to both. PR 3: Backfill old data. PR 4: Read from new. PR 5: Drop old column.

## 17. Final Interview Advice

> BAE's Top Tip:
> Don't just memorize these patterns. Understand *why* they exist. 
> In a real interview, the interviewer cares more about how you communicate tradeoffs than whether you wrote a perfect one-liner.
> If you get stuck, always verbalize your thought process! "I know a hash map gives O(1) lookup, but it will cost O(N) space. Let's start with that and optimize later."
