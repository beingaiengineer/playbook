## 14. Production Notes

> Production Note:
> Algorithmic thinking matters in production when data size grows or latency becomes visible. An O(n^2) loop might run fine locally with 10 records, but will completely bring down your backend when deployed to production handling 100,000 active users.

---

### Advanced Top Patterns to Master
1. **Sliding Window**: Use this when dealing with contiguous sub-arrays or substrings (e.g., "Longest substring without repeating characters"). It drops complexity from O(n^2) to O(n).
2. **Two Pointers**: Crucial for sorted arrays (e.g., "Two Sum II"). You place one pointer at the start and one at the end, moving inward based on a condition.
3. **Top K Elements (Heap)**: Whenever you see "Find the Top K", "Kth largest", or "Kth most frequent", immediately reach for Python's `heapq` module.
4. **Depth-First Search (DFS) vs Breadth-First Search (BFS)**:
   - Use **DFS** (via recursion or a stack) when you need to explore all possibilities (e.g., finding all paths in a maze).
   - Use **BFS** (via `collections.deque`) when you need the *shortest* path in an unweighted graph.
