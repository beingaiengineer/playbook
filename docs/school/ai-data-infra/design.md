# Course: Advanced AI Data Infrastructure

## Why This Course?
AI agents and LLMs are only as smart as the data they can retrieve. Traditional relational databases aren't enough for semantic search or high-speed document retrieval. We explore the specialized data stores powering the next generation of AI applications.

## Core Topics
1.  **Vector Databases**
    *   Embeddings and Vector Search theory.
    *   Deep-dive: Pinecone, Qdrant, Milvus.
2.  **NoSQL & Document Stores**
    *   When SQL isn't enough.
    *   MongoDB, DynamoDB, and unstructured data ingestion.
3.  **Graph Databases**
    *   Neo4j and Knowledge Graphs.
    *   Feeding structured knowledge into Agentic workflows.
4.  **Data Pipelines (ETL/ELT)**
    *   Ingesting, transforming, and syncing data at scale (Airflow, dbt basics).
