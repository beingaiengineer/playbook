# Course: Cloud Infrastructure & Containers

## Why This Course?
Code on your local machine is useless to users. Understanding how code is packaged, shipped, and orchestrated in the cloud is non-negotiable for modern AI-native backend engineers.

## Core Topics
1.  **Containerization**
    *   Docker Fundamentals: Images, Containers, Volumes, and Networks.
    *   Writing optimized, secure Dockerfiles for Python/Node apps.
2.  **Container Orchestration**
    *   Kubernetes (K8s) Basics: Pods, Deployments, Services.
    *   Managing ConfigMaps and Secrets.
3.  **Infrastructure as Code (IaC)**
    *   Terraform Fundamentals: State, Providers, Resources.
    *   Automating Cloud provisioning securely.
4.  **Serverless & Cloud-Native**
    *   AWS Lambda, Google Cloud Run.
    *   Trade-offs between managed services and self-hosted infrastructure.
