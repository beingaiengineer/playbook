## 2. Engineering Story
During a massive data migration for a Fortune 500 retailer, our ingestion pipeline was choking on a list of 50 million transaction objects. The CPU was spinning, but throughput was garbage. We profiled the system and realized we were suffering from terrible cache misses because the data was scattered across memory as object references. By packing the primitive values into contiguous arrays (a struct-of-arrays approach), we saturated the CPU cache lines and the ingestion job finished 40x faster, bro.

## 4. Concept Explanation
An array is a contiguous block of memory where each element is the same size. Because memory addresses are sequential, CPUs can prefetch chunks of the array into their ultra-fast L1/L2 caches (cache lines). This makes iterating over arrays incredibly fast compared to structures where nodes are scattered in memory.

## 10. Top Interview Questions
| Question | Answer |
|---|---|
| Why are arrays faster to iterate than linked lists? | Because arrays are contiguous in memory, allowing the CPU to load multiple elements into a cache line at once. Linked lists cause cache misses. |
| What are the drawbacks? | Dynamically resizing arrays (like Python lists or C++ std::vector) involves allocating a larger block and copying all elements, which can cause latency spikes if not pre-allocated correctly. |
| When should this be avoided? | Use arrays if you need to frequently insert or delete elements at the beginning or middle, as it requires shifting elements. |
| What is the space complexity? | O(n) |
| How does it compare to its main alternative? | Depends strongly on cache locality and the exact access pattern. |

## 11. Tricky Questions & Edge Cases
If you use a dynamic array (like a Python list) and continuously append elements, it eventually has to resize itself. This requires allocating a new, larger block of memory and copying all elements over. A single append operation could theoretically take O(n) time during a resize, though it's O(1) amortized.

| DO | DON'T |

## 14. Production Notes
