## 4. Concept Explanation
A Graph consists of vertices (nodes) connected by edges. They can be directed or undirected, weighted or unweighted. Traversing them requires algorithms like Depth-First Search (DFS) for deep exploration (like cycle detection) or Breadth-First Search (BFS) for finding the shortest path in unweighted networks.

## 6. Beginner Example
```python
graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': [],
    'D': []
}

def dfs(graph, node, visited):
    if node not in visited:
        visited.add(node)
        for neighbor in graph[node]:
            dfs(graph, neighbor, visited)
```

## 7. Real-World Engineering Example
```python
from collections import deque

def shortest_path(graph, start, end):
    queue = deque([(start, [start])])
    visited = set([start])

    while queue:
        node, path = queue.popleft()
        if node == end:
            return path

        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None
```

## 10. Top Interview Questions
| Question | Answer |
|---|---|
| How do you detect a cycle in a directed graph? | Use DFS and keep track of the recursion stack. If you visit a node that is currently in the recursion stack, a cycle exists. |
| What are the drawbacks? | Recursive DFS can hit recursion depth limits on massive graphs. Use an iterative approach with a stack for production systems. |
| When should this be avoided? | Represent dense graphs (many edges) as adjacency lists; use an adjacency matrix instead for O(1) edge lookups. |
| What is the space complexity? | O(V) |
| How does it compare to its main alternative? | Depends strongly on cache locality and the exact access pattern. |

## 11. Tricky Questions & Edge Cases
A node can be visited multiple times in DFS if it's reachable via different paths, unless you maintain a global `visited` set.

## 12. Real-World Usage

## 13. Best Practices
| DO | DON'T |
|---|---|
| Always keep a `visited` set during traversal to prevent infinite loops. | Represent dense graphs (many edges) as adjacency lists; use an adjacency matrix instead for O(1) edge lookups. |

## 14. Production Notes
> **Warning**: Recursive DFS can hit recursion depth limits on massive graphs. Use an iterative approach with a stack for production systems.

## 15. Common Mistakes
| Mistake | Correction |
|---|---|
| Using DFS to find the shortest path in an unweighted graph. | Always use BFS for shortest-path problems in unweighted graphs to guarantee the earliest discovery is the shortest. |
