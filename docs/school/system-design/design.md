# Course: System Design & Distributed Systems

## Why This Course?
A single server running Python code can only handle so much traffic before it crashes. Software engineers must understand how to distribute load, manage state across machines, and design resilient systems that scale gracefully. We teach the fundamentals of modern architecture so students stop building "toy" apps and start building production-ready platforms.

## Core Topics
1.  **Architecture Fundamentals**
    *   Monoliths vs Microservices: When to use what.
    *   Stateless vs Stateful Systems.
2.  **Traffic & Routing**
    *   DNS, Load Balancers, and Reverse Proxies (Nginx, Traefik).
    *   API Gateways and Rate Limiting.
3.  **Data Storage & Caching**
    *   Database Scaling: Read Replicas, Partitioning, Sharding.
    *   Caching Strategies: Redis, Memcached, CDN.
4.  **Asynchronous Processing**
    *   Message Queues & Event-Driven Architecture (Kafka, RabbitMQ, SQS).
    *   Background Workers (Celery, RQ).
