# MetaGPT (Software Company Simulation)

| Area | Details |

## 2. Engineering Story

Bro, if you want an LLM to build a web app, you prompt it. It spits out 500 lines of spaghetti code in one file. Half the functions don't connect.
How do *real* humans build software? A Product Manager writes a PRD (Product Requirements Document). An Architect designs the system API. An Engineer writes the code. A QA tester writes unit tests.
**MetaGPT** digitizes this exact process. You assign roles to AI agents and enforce **Standardized Operating Procedures (SOPs)**. You type: "Build a Flappy Bird clone." MetaGPT's PM writes a markdown PRD. The Architect generates mermaid diagrams. The Engineer writes the Python files. The result is a fully structured, professional codebase.

## 4. Concept Explanation

MetaGPT pioneered the concept of **SOP-driven Multi-Agent Systems**.
Instead of agents chatting freely in an unstructured group chat (like AutoGen), agents in MetaGPT communicate primarily by publishing standardized documents (Environment). 
1. **Roles**: Pre-defined personas (e.g., `ProductManager`, `Architect`, `Engineer`).
2. **Actions**: Specific tasks a role must perform (e.g., `WritePRD`, `WriteDesign`, `WriteCode`).
3. **Environment**: A shared message board. When the PM finishes the PRD, they pin it to the board. The Architect is subscribed to PRDs, wakes up, and starts their action.

## 6. Beginner Example

Starting a MetaGPT software company with a single command using their built-in roles.

```python
# pip install metagpt
import asyncio
from metagpt.team import Team
from metagpt.roles import ProductManager, Architect, ProjectManager, Engineer

async def startup():
    # 1. Create a Team (Software Company)
    company = Team()
    
    # 2. Hire the employees
    company.hire([
        ProductManager(),
        Architect(),
        ProjectManager(),
        Engineer()
    ])
    
    # 3. Give them funding/budget (token limit)
    company.invest(investment=3.0)
    
    # 4. Give the CEO (You) requirement
    idea = "Write a python CLI tool that plays Tic-Tac-Toe in the terminal."
    
    # 5. Let the company run!
    await company.run(idea=idea)

asyncio.run(startup())
```
*When this runs, MetaGPT creates a `workspace/` folder and saves the PRD.md, SystemDesign.md, and the final `main.py` files iteratively.*

## 7. Real-World Engineering Example

You can build custom SOPs beyond software development. Here is an example of an AI Marketing Agency.

```python
from metagpt.roles import Role
from metagpt.actions import Action
from metagpt.team import Team

# 1. Define custom Actions (SOPs)
class WriteSEOArticle(Action):
    async def run(self, topic: str):
        prompt = f"Write a 500 word SEO optimized article about {topic}."
        return await self._aask(prompt)

class ReviewArticle(Action):
    async def run(self, article: str):
        prompt = f"Review this article for grammar. Output the fixed version:\n{article}"
        return await self._aask(prompt)

# 2. Define Roles and assign their Actions
class Writer(Role):
    def __init__(self):
        super().__init__(name="Alice", profile="SEO Writer")
        self.set_actions([WriteSEOArticle])
        
class Editor(Role):
    def __init__(self):
        super().__init__(name="Bob", profile="Senior Editor")
        self.set_actions([ReviewArticle])
        # The Editor subscribes to outputs from the Writer!
        self._watch([WriteSEOArticle])

# 3. Run the team
# ... (Team setup similar to beginner example)
```

## 10. Top Interview Questions
| Question | Answer |
|---|---|
| What is an SOP in MetaGPT? | Standardized Operating Procedure. It forces the LLM to output its thoughts in a very strict format (like a markdown table or a specific class structure) before the next agent takes over, drastically reducing hallucination. |
| How do agents communicate in MetaGPT? | Not via direct group chat. They communicate via a Publish/Subscribe model. Agent A publishes an artifact to the Environment. Agent B is "watching" for that specific artifact type, wakes up, and processes it. |
| What makes MetaGPT better at writing software than ChatGPT? | ChatGPT has to hold the entire project context in its immediate memory. MetaGPT serializes the context into files (PRD, System Design) and uses specialized agents to focus purely on one file at a time, mimicking human engineering processes. |

## 11. Tricky Questions & Edge Cases

Bro, what happens if the Engineer agent writes code that conflicts with the Architect's design?
In early versions, this was a huge problem. MetaGPT solves this by injecting an `ActionNode` loop. The QA/Tester agent attempts to run the Engineer's code. If it throws an error, the error log is published back to the Environment. The Engineer is subscribed to errors, wakes up, reads the log, and patches the code. It is an autonomous CI/CD loop.

## 12. Real-World Usage

- **Automated MVP Generation**: Founders using MetaGPT to generate the boilerplate React/FastAPI code for a startup idea overnight.
- **Data Engineering Factories**: A team of MetaGPT agents configured to ingest dirty CSV files, write a Pandas cleaning script, test the script, and output clean Parquet files.

## 13. Best Practices
| DO | DON'T |
|---|---|
| Use MetaGPT for complex, multi-step document generation tasks | Use MetaGPT for simple Q&A chatbots |
| Override `_watch()` to strictly define the Pub/Sub dependency graph | Let all agents watch all messages (creates chaos) |
| Use GPT-4 or Claude 3.5 Sonnet | Attempt to run MetaGPT on Llama-7B (it fails to follow SOP formatting) |

## 14. Production Notes
> Production Note:
> MetaGPT relies heavily on executing the code it generates locally (e.g., running `python main.py` to test it). In production, you CANNOT run this on your bare-metal API server. You must integrate MetaGPT with isolated Docker containers or Firecracker microVMs, otherwise the generated code can compromise your host infrastructure.

## 17. Advanced Mechanics (Action Nodes)
1. **ActionNodes**: To guarantee that an LLM outputs the exact format required by an SOP, MetaGPT uses ActionNodes. Under the hood, these map to OpenAI's structured JSON output or Pydantic parsers, ensuring the `Architect` doesn't just write a paragraph, but strictly returns a dictionary containing `{"mermaid_diagram": "..."}`.
2. **Incremental Development**: Modern MetaGPT supports resuming projects. You can point the `Team` at an existing codebase, provide a new PRD ("Add a login page"), and the agents will read the existing code and apply diffs rather than generating from scratch.

## 15. Common Mistakes
- **Under-funding the Investment**: Setting `company.invest(0.1)` (10 cents). Generating a complex app requires dozens of GPT-4 calls. The company will go "bankrupt" halfway through generating the architecture and crash.
- **Ignoring the Workspace**: Wondering where the output went. MetaGPT saves all artifacts to the local disk in a `/workspace` directory, not just in memory.
