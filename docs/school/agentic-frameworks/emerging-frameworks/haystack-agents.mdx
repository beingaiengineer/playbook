Think of Haystack like a factory assembly line.
In a factory, a raw material (User Prompt) enters the building. A sorting machine (Router) looks at it. If it's metal, it sends it to the welder (Code Executor). If it's wood, it sends it to the saw (RAG Retriever). Haystack pipelines are rigid, predictable, and highly efficient assembly lines for AI.

## 4. Concept Explanation

Haystack (by deepset) was originally designed for enterprise Search and RAG. With Haystack 2.0, they introduced **Agentic Pipelines**.
The core primitives are:
1. **Components**: The building blocks (e.g., `PromptBuilder`, `OpenAIGenerator`, `QdrantRetriever`).
2. **Pipelines**: The graph that connects components together.
3. **Conditional Routing**: Components that evaluate data and dynamically route execution down different branches of the pipeline, creating "Agentic" decision-making without relying entirely on LLM reasoning.

## 5. Syntax Table
| Concept | Code | Description |
|---|---|---|
| Initialize Pipeline | `pipe = Pipeline()` | Creates the DAG graph. |
| Add Node | `pipe.add_component("llm", OpenAIGenerator())` | Adds a processor to the graph. |
| Connect Nodes | `pipe.connect("retriever", "llm")` | Wires the output of A to the input of B. |

## 6. Beginner Example

A simple Haystack 2.0 Pipeline that builds a prompt and generates a response.

```python
# pip install haystack-ai
from haystack import Pipeline
from haystack.components.builders import PromptBuilder
from haystack.components.generators import OpenAIGenerator

# 1. Define the components
prompt_template = "Translate the following to French: {{text}}"
prompt_builder = PromptBuilder(template=prompt_template)
llm = OpenAIGenerator(model="gpt-4o") # Requires OPENAI_API_KEY env var

# 2. Create the Pipeline
pipe = Pipeline()
pipe.add_component("builder", prompt_builder)
pipe.add_component("llm", llm)

# 3. Connect them (Output of builder goes into LLM)
pipe.connect("builder", "llm")

# 4. Run the pipeline!
result = pipe.run(
    data={
        "builder": {"text": "Hello, how are you today?"}
    }
)

print(result["llm"]["replies"][0]) # "Bonjour, comment allez-vous aujourd'hui ?"
```

## 7. Real-World Engineering Example

In production, you use Conditional Routers to make "Agentic" pipelines that branch dynamically.

```python
from haystack import Pipeline
from haystack.components.routers import ConditionalRouter
from haystack.components.generators import OpenAIGenerator
from haystack.components.builders import PromptBuilder

# 1. Define Routing Logic
routes = [
    {
        "condition": "{{'math' in query.lower()}}",
        "output": "{{query}}",
        "output_name": "math_route",
        "output_type": str,
    },
    {
        "condition": "{{'poem' in query.lower()}}",
        "output": "{{query}}",
        "output_name": "poem_route",
        "output_type": str,
    },
]

router = ConditionalRouter(routes)

# 2. Define specialized generators
math_llm = OpenAIGenerator(system_prompt="You are a strict mathematician. Output only numbers.")
poem_llm = OpenAIGenerator(system_prompt="You are Shakespeare. Answer in iambic pentameter.")

# 3. Build Pipeline
pipe = Pipeline()
pipe.add_component("router", router)
pipe.add_component("math_llm", math_llm)
pipe.add_component("poem_llm", poem_llm)

# 4. Connect routes to specific components!
pipe.connect("router.math_route", "math_llm.prompt")
pipe.connect("router.poem_route", "poem_llm.prompt")

# 5. Run - The router evaluates the string and sends it down ONE path
pipe.run(data={"router": {"query": "Write me a poem about AI."}})
```

## 10. Top Interview Questions
| Question | Answer |
|---|---|
| Why use Haystack instead of LangChain? | Haystack explicitly forces you to define your execution graph (Pipeline) upfront using `.connect()`. This makes it vastly easier to debug, visualize, and deploy to production than LangChain's highly abstracted magic. |
| What is a Haystack Component? | A standalone Python class with a `@component` decorator and a `run()` method. It takes strict typed inputs and returns a dictionary of outputs. |
| How do Haystack pipelines loop? | By connecting the output of a downstream node back to the input of an upstream node, creating cycles (useful for self-correcting agents). |

## 11. Tricky Questions & Edge Cases

Bro, what happens if you try to connect `Retriever` output to `OpenAIGenerator` input, but the types don't match?
Haystack's `.connect()` method performs strict validation *before* the pipeline runs. If Node A outputs `List[Document]` and Node B expects `str`, Haystack throws a `PipelineConnectError` immediately. This saves you from runtime crashes in production! You must insert a `PromptBuilder` between them to convert the Documents into a String.

## 12. Real-World Usage

- **Enterprise Document Search**: Replacing internal Elasticsearch instances with a Haystack Pipeline that embeds queries, searches Pinecone, reranks the top 10 results using a Cohere Reranker, and synthesizes a final answer.
- **Multimodal Agents**: A pipeline that routes image inputs to a vision model (GPT-4-Vision) and text inputs to a standard model (GPT-4o), merging the outputs into a single JSON response.

## 13. Best Practices
| DO | DON'T |
|---|---|
| Use explicit Conditional Routers for branching logic | Rely on the LLM to autonomously decide every single step |
| Draw out your pipeline DAG on a whiteboard first | Start coding `.connect()` blindly |
| Use Haystack's built-in telemetry / tracing | Deploy blindly to production |

## 17. Advanced RAG & Reranking
1. **Rerankers**: In advanced Haystack pipelines, you don't just trust the Vector Database. You retrieve 50 documents, then pass them through a `SentenceTransformersRanker` (a specialized cross-encoder model). It re-scores and re-orders the 50 documents against the user's query, returning only the top 3 most relevant ones to the LLM. This drastically reduces hallucinations.
2. **WebSearch Integration**: You can add a `SerperDevWebSearch` component alongside your Vector Database retriever, and use a `DocumentJoiner` to merge internet results with your private company data before feeding it to the prompt.

## 15. Common Mistakes
- **Hanging Pipelines**: Creating cycles (loops) without a clear exit condition in the router. The pipeline will loop endlessly until it hits recursion limits.
- **Passing raw dictionaries**: Trying to pass raw JSON into a Node instead of using Haystack's official `Document` class, which breaks downstream components that expect strict typing.
