## 4. Concept Explanation

To deploy Semantic Kernel in Python, the industry standard is to wrap it inside a **FastAPI** application.
Because Semantic Kernel relies heavily on network calls (to OpenAI, to Vector Databases, to external APIs), it is inherently I/O bound. FastAPI's asynchronous architecture pairs perfectly with SK's `async/await` design.
In enterprise environments (especially Azure), you avoid raw API keys. Instead, you use `AzureOpenAIChatCompletion` combined with `DefaultAzureCredential` to authenticate seamlessly via IAM roles without ever storing secrets in your code.

## 6. Beginner Example

The absolute minimum viable production setup using FastAPI and Uvicorn.

```python
from fastapi import FastAPI, HTTPException
import semantic_kernel as sk
import semantic_kernel.connectors.ai.open_ai as sk_oai
from pydantic import BaseModel
import os

app = FastAPI()

# 1. Initialize Kernel globally so we don't rebuild it on every request
kernel = sk.Kernel()
kernel.add_service(
    sk_oai.OpenAIChatCompletion(
        service_id="default", 
        ai_model_id="gpt-4o", 
        api_key=os.environ["OPENAI_API_KEY"]
    )
)

class ChatRequest(BaseModel):
    user_message: str

@app.post("/api/chat")
async def chat_endpoint(req: ChatRequest):
    try:
        # 2. Invoke the kernel asynchronously!
        result = await kernel.invoke_prompt(req.user_message)
        return {"response": str(result)}
    except Exception as e:
        # 3. Never leak raw stack traces to the client
        print(f"Error: {e}")
        raise HTTPException(status_code=500, detail="Internal Server Error")
```
Run this with: `uvicorn main:app --workers 4`

## 7. Real-World Engineering Example

In a real enterprise (e.g., Azure), you want streaming responses (Server-Sent Events) and Managed Identity authentication.

```python
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import semantic_kernel as sk
from semantic_kernel.connectors.ai.open_ai import AzureChatCompletion
from azure.identity import DefaultAzureCredential

app = FastAPI()
kernel = sk.Kernel()

# 1. Enterprise Security: No API Keys! Uses the VM's IAM Role.
credential = DefaultAzureCredential()
azure_service = AzureChatCompletion(
    service_id="default",
    deployment_name="gpt-4-enterprise",
    endpoint="https://my-enterprise-ai.openai.azure.com/",
    ad_token_provider=credential.get_token
)
kernel.add_service(azure_service)

@app.post("/api/stream")
async def stream_endpoint(prompt: str):
    # 2. Generator function to yield tokens as they arrive
    async def token_generator():
        try:
            # invoke_stream returns an AsyncGenerator of chunks
            async for chunk in kernel.invoke_prompt_stream(prompt):
                yield f"data: {chunk[0].text}\n\n"
        except Exception as e:
            yield f"data: [ERROR]\n\n"
            
    # 3. Return a Server-Sent Events (SSE) stream
    return StreamingResponse(token_generator(), media_type="text/event-stream")
```

## 10. Top Interview Questions
| Question | Answer |
|---|---|
| Why use FastAPI instead of Flask for Semantic Kernel? | Semantic Kernel is built entirely around Python `asyncio`. Flask is traditionally synchronous. FastAPI natively supports `async def` routing, allowing your server to handle thousands of concurrent SK requests without blocking threads. |
| What is a Managed Identity / DefaultAzureCredential? | It is a cloud security feature where the server running your code assumes an IAM role to authenticate with Azure OpenAI, entirely eliminating the need to hardcode or store `OPENAI_API_KEY` in your `.env` files. |
| Why is Streaming (Server-Sent Events) critical in production AI apps? | LLM generation is slow. If an answer takes 10 seconds to generate, a blocking request will make the user stare at a frozen screen. Streaming returns words instantly as they are generated, vastly improving perceived performance. |

## 11. Tricky Questions & Edge Cases

Bro, what happens if your `StreamingResponse` fails halfway through?
If the OpenAI API cuts the connection at token 500 out of 1000, your generator will throw an `httpx.ReadError`. If you don't wrap the `async for` loop in a `try/except` block, the HTTP connection will drop abruptly, crashing the user's UI. Always catch streaming exceptions and yield a graceful error token (e.g., `data: [Network Error - Generation Halted]`).

## 13. Best Practices
| DO | DON'T |
|---|---|
| Use `StreamingResponse` for all chat-facing endpoints | Make users wait 15 seconds for a synchronous `invoke()` |
| Catch and obfuscate errors (return HTTP 500) | Leak prompt templates or traceback logs to the client |
| Initialize the `kernel` object globally on server startup | Re-initialize the Kernel and re-import all plugins on every single API request |

## 14. Production Notes
> Production Note:
> Semantic Kernel has a built-in telemetry system (using OpenTelemetry). In production, you should hook this up to Azure Application Insights, Datadog, or Jaeger. It automatically traces the exact duration of every plugin execution, the exact prompt sent to the LLM, and the token usage. This is critical for debugging why a specific request took 12 seconds.

### Advanced Security (Filters)
1. **Function Filters**: SK provides an `IFunctionInvocationFilter` interface. You can register a global filter that runs *before* any Native Function executes. You can use this to intercept a `DeleteDatabase()` tool call, check the `request.headers` for a valid Admin JWT token, and cancel the execution if the user is unauthorized.
2. **Prompt Filters**: Similarly, you can register an `IPromptRenderFilter`. This runs right before the string is sent to OpenAI. You can hook this up to a PII (Personally Identifiable Information) scrubber to redact Social Security Numbers before they leave your VPC.

## 15. Common Mistakes
- **Global State Pollution**: Storing user-specific conversation history directly inside a global `Kernel` object. If User A and User B hit the server concurrently, User B might see User A's chat history! Always maintain Chat History per-session/per-request.
- **Blocking the Event Loop**: Calling `time.sleep(5)` or `requests.get()` inside a Native Plugin. Since SK runs asynchronously, synchronous blocking calls will freeze the entire FastAPI web server. Always use `await asyncio.sleep()` or `httpx.AsyncClient`.
